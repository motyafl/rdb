# RDB (Roman Data Browser)

[English](README.md) | [Русский](README.ru.md)

**RDB** - веб-сервис для индексации, визуализации и сквозного анализа данных космического телескопа NASA **Nancy Grace Roman**. Платформа собирает массивы данных с широкоугольной камеры телескопа (WFI) в единую интерактивную карту-мозаику, позволяя исследователям мгновенно оценить состояние всех 18 детекторов сразу и перейти к глубокой аналитике любого отдельного сенсора прямо в браузере.

* **Панорамный обзор матрицы:** уменьшенные превью снимков со всех 18 детекторов WFI отображаются одновременно в строгом соответствии с их реальной геометрией в фокальной плоскости.
* **Быстрая навигация по S3:** облегченный индекс файловой структуры позволяет находить нужные данные по участку неба без ручного поиска по запутанным архивам и скачивания гигабайтов сырых файлов.
* **Глубокий анализ в один клик:** при выборе любого детектора на мозаике открываются его полные метаданные, научные параметры и интерактивные графики с гибкой настройкой.

## Зачем нужен RDB?

Поле зрения телескопа Nancy Grace Roman в 100 раз больше, чем у Hubble, при сопоставимой четкости снимков. Каждая экспозиция широкоугольной камеры WFI формирует терабайты данных с 18 отдельных матричных сенсоров, что создает серьезные сложности при работе с релизами:

* **Сложная файловая структура:** архивы релизов огромны, из-за чего тяжело быстро найти файлы конкретного сенсора для нужного участка неба.
* **Отсутствие общей картины:** нет удобного инструмента, чтобы увидеть всю 18-сенсорную мозаику в одном окне и сразу оценить качество съемки.
* **Тяжелый локальный анализ:** чтобы поменять параметры визуализации или построить базовые графики, ученым приходится выкачивать гигабайты исходников из облачных S3-хранилищ на свои компьютеры.

RDB решает эти задачи по принципу «от общего к частному»: бэкенд на Python индексирует и оптимизирует массивы данных из S3 на лету, а фронтенд на React обеспечивает интерактивную работу с мозаикой, оптическими фильтрами, контрастностью и графиками прямо в браузере.

## Архитектура

Платформа разделена на три функциональных уровня:

1. **Комплексный мониторинг (Dashboard):** модуль на Python запрашивает данные из облачного S3-хранилища, оптимизирует исходные массивы и формирует единую карту-мозаику из 18 детекторов.
2. **Детализация детектора:** при клике на любой узел матрицы интерфейс на React открывает изолированный вид сенсора с полными метаданными, телеметрией и научными зависимостями.
3. **Параметрическая кастомизация:** встроенные инструменты позволяют менять оптические фильтры, диапазоны частот, уровни контрастности и конфигурацию графиков без повторной загрузки сырых данных.

## Быстрый старт

### Требования

* Node.js (v22+)
* Python (3.10+)

### Установка и запуск

Клонируйте репозиторий и установите зависимости фронтенда:

```bash
git clone git@github.com:motyafl/rdb.git
cd rdb
npm install
```

Запустите сервер для разработки:

```bash
npm start
```

## Участие в разработке

Проект находится в активной разработке в преддверии публикации первых научных релизов телескопа Roman. Предложения по улучшению, баг-репорты и pull request'ы приветствуются.
